Как настроить уведомления
1. Нажмите «Добавить сценарий»
2. В появившемся окне выберите «Перейти к настройкам»
3. Отметьте события для отслеживания
4. Выберите способ оповещения
5. Добавьте получателей уведомлений
6. Нажмите «Добавить» для сохранения сценария
